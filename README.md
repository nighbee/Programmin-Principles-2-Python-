## Getting started

Most folders are independent projects. Enter a project directory, inspect its Python entry point, and install only the dependencies required by that project.

Example:

```bash
cd 1StreamLit
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt  # when provided
streamlit run app.py                    # when app.py is the entry point
```
